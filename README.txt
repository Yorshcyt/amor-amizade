amor&amizade — GitHub Pages

1. Crie um repositório no GitHub.
2. Extraia este ZIP e envie o conteúdo da pasta para a raiz do repositório: index.html, assets, .nojekyll e este README.
3. Em Settings → Pages, escolha Deploy from a branch → main → /(root) → Save.
4. Aguarde a publicação e abra o endereço mostrado pelo GitHub.

Inclui a cidade com cinco meios de transporte, a faculdade com 20 setores e trajetos apenas a pé, além do gerador de abertura dos dias com dados de clima e layout para celular.
No gerador, informe apenas data e horário. Rolar o dia sorteia o clima em 1d100, a temperatura e a descrição. Não há configurações de tempo para ficarem travadas.
Todos os recursos funcionam no navegador, sem APIs nem instalação.
Não abra index.html diretamente pelo gerenciador de arquivos; use o endereço publicado.
Os tempos são estimativas para o RPG. O histórico e as escolhas ficam em cada navegador; compartilhem as aberturas copiando o texto.
O ZIP não contém contas, credenciais, integração com Telegram ou dados privados de acesso ao site.
O acesso no GitHub Pages depende da configuração do seu repositório, independentemente do site atual.

Nesta atualização: escala do campus calibrada pelo campo de futebol que aparece nos dois mapas; acessos da Fisioterapia e passeios internos corrigidos; cada clique em um setor inicia o próximo trecho no destino anterior.
Os arquivos usam identificadores de versão para evitar reaproveitar código antigo do cache.

Os arquivos continuam separados: index.html e a pasta assets. No computador, envie o conteúdo extraído do ZIP para a raiz do repositório, preservando a pasta assets, e faça Commit changes.
Fisioterapia e Ciências Contábeis aparecem apenas no mapa da faculdade, com seus trajetos dentro do campus. Foram removidos os textos e os destinos desses cursos do mapa da cidade.
